## 通用配方個人化（2026-09-08）

- 光色由**物件自己嘅像素**量出嚟（`accentOf()`：遮罩內平均色 → HSL，飽和度 <.08 當中性保留原本青色）。香蕉出琥珀、士多啤梨出珊瑚紅、鋼樽維持冷色。唔係一種房子色塗晒所有嘢。
- 骨架比例由剪影推：`seed` 來自 kept／闊／高，`vary()` 決定核心收窄比例、外框厚度、橫撐間距、兩個模組嘅位置同大細。**完全確定性**（`build()` 每次切配方都會重跑，同一張相一定同一個未來），唔用亂數 —— 同 README 講咗嘅「稀有度由幾何算」同一原則。
- 檢查照樣全綠（含 `build() is re-runnable without drift`）。

## 仰角重新投影原型（2026-09-06，已做）

`flask(elev)` 加咗仰角參數，滑桿由正面掃到 45°。**只係程序幾何**；相片保留部分
（鋼蓋、樽底）仍然係平視鏡頭嘅一張相，跟住一齊垂直壓縮而已。

**數學**：水平圓環半徑 `r` 喺仰角 φ 投影成半短軸 `r·sin(φ)`，垂直方向前縮 `cos(φ)`。

- 踩過一次坑：**唔可以用單一個成長係數乘所有橢圓。** 啲橢圓唔係同一個授權仰角畫：
  鰭係 `ry/rx=.085`（≈4.9°），但樽蓋膠圈係 `6/29=.207`（≈11.9°）。用單一係數會令
  本身已經開咗嘅元素**過度旋轉 2.4 倍**，樽蓋同底座變成兩個大黑圓餅。
- 正解：每個元素由**佢自己嘅授權仰角**起計，一齊轉同一個角度差
  `RY(rx,ry0)=rx·sin(asin(ry0/rx)+Δ)`。Δ=0 時每個橢圓原封不動還原。
- **仰角 0 係代數上恆等**（`g=1`、`k=1`），唔係「睇落差唔多」。

**最重要嘅發現：可用範圍比預期窄好多。**

甜區大約 **15–25°**。超過 ~30°，啲鰭環嘅 `ry` 超過 24px 嘅鰭距，成疊環互相重疊，
**設計賴以成立嘅負空間消失**，45° 就變成一嚿冇性格嘅圓球。呢個係幾何上正確
（真實散熱鰭由上望落去就係咁密），唔係 bug，但**佢係一個真實嘅設計約束**。

→ **修正之前嘅硬件建議**：第二個鏡頭如果加，對**高身物件**應該係 ~20–25°，

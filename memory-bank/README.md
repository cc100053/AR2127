## 三十秒版本

觀眾放一件日常物品（鑰匙、交通卡、護唇膏）落旋轉台座，
系統即時推演並疊加**呢件物品一百年後嘅形態**，最後印一張實體預測書。

- 前端係單一 `index.html`，零建置、零依賴
- 幾何（追蹤、輪廓、形態推演）本地每格跑；Gemini 一次循環只叫一次
- 而家全部係假資料。後端 `:7127`（Gemini 代理 + 熱感應印表機）**一行都未寫**

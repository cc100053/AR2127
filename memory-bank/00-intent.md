# 00 · 核心主旨與紅線

## 主旨

> 將一件現代物品**向前推一百年**，畀觀眾睇到：
> **「你呢件嘢，2127 年會變成點樣。」**

觀眾放低自己嘅鑰匙，睇到嘅係**佢自己嗰條鑰匙，演化咗一百年之後嘅樣**。
情感落點係**認得出 + 驚訝**，唔係搞笑。

## 紅線：唔可以變成「遺物鑑定」

呢個偏離**已經發生過一次**，而且改返嗮好貴（文案 + schema + 視覺三層都要動）。

### 點解會偏離

因為「2127 年嘅視角」好自然咁滑向「未來人回望現在」。
一寫「2127 Archaeologist AI」做 prompt persona，成條線就倒轉。
**Persona 應該係推演器／預測器，唔係考古學家。**

## 視覺上點樣先算做到主旨

**只係喺物體外面畫一條貼身輪廓 = 畫面上講緊「佢冇變過」。** 呢個唔算數。

一定要同時見到**兩個唔同嘅形態**：

- **2026 原型** —— 真實物體本身，形變後退成虛線
- **2127 形態** —— 一條**唔同嘅**輪廓：更流線、長咗新結構、大一圈
- **對應連線** —— 兩者之間嘅放射線，直接畫出「呢個 → 變成呢個」

實作喺 `projectFuture()`（見 `10-architecture.md`）。
`形變量`（morph）係真實可量嘅數，唔係裝飾。

## 情感落點：`kept`

Gemini 回傳嘅欄位入面，**`kept` 最重要**：一百年之後**仍然冇變**嗰件事。

> 「仲係要揸喺手，仲係會唔見。」
> 「一百年之後，佢仲係要你用隻手掟出去。」

規格幾炫都只係包裝。**呢句先係令人影相嗰句。**
所以佢排喺最尾出場、用主題色、字大過其他。改版時唔好削佢。
